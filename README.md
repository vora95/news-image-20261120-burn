against Myanmar, and eight more), a schematic world map pinning where each
featured story happened, and 25 more stories in the ALSO ON list — from
Anthropic's record IPO to Gukesh arriving in Geneva for his title defence.

the output directory — no network, no randomness, fully deterministic.
